# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |

## Reporting a Vulnerability

If you discover a security vulnerability in ShadowBox (such as a sandbox escape, sensitive environment leak, or process isolation flaw):

1. Please do not open a public issue.
2. Report the vulnerability privately via GitHub Security Advisories at https://github.com/Nari-Ab/shadowbox/security/advisories/new or contact the maintainers directly.
3. Include detailed steps to reproduce the issue and expected vs actual behavior.

We take security reports seriously and will acknowledge receipt within 48 hours.
